🧪 MintDesk

Frankenstein lab for solo builders: verify a BSC contract, triage it like a Jira ticket, let the Crew watch it. Read-only — no wallet, no signing, no transactions.

Kiroween 2026 · Frankenstein BSC · read-only Built with Kiro

1 · Verify a contract

Paste a BSC contract address. MintDesk reads bytecode, name/symbol/supply/owner and the Sourcify source match, then scores it 0–100.

2 · Verify an Agent ID

Read-only handleOf() call to the Agent ID registry. Checks that a wallet actually owns the claimed handle.

3 · Triage queue

Tickets persist in your browser (localStorage). Demo tickets are labelled DEMO — delete them when you start real triage.

New manual ticket

4 · Watchlist

Contracts you want re-checked later. Re-check runs the same deterministic verification and updates the score in place. The Kiro Crew watch agent (see .kiro/crew/watch-agent.md) is the automation spec for this list — it polls, it never transacts.

MintDesk is a Kiroween 2026 entry (Frankenstein category). Built fresh for the hackathon with Kiro; verification patterns were inspired by the author's earlier MintGuard work — no MintGuard code was copied. All on-chain reads use public BSC RPC endpoints and Sourcify; nothing here connects a wallet, signs, or sends a transaction. Demo data is labelled DEMO.
